# 01 — Recommend jobs from a profile

**What to build:** A user supplies a current role or work summary and any stated skills or qualifications. The model returns a short, ranked list of relevant jobs now, with a concise reason for each recommendation.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] A profile with a current role or work summary produces ranked jobs from the full collection, not only saved browsing suggestions.
- [ ] The output explains role and skill matches and keeps missing profile facts distinct from unmet requirements.
- [ ] Before sending real profile fields to Gemini, confirm which personal fields the product permits the service to receive. Use non-personal example profiles for development until then.
